# Histórias de uso

Histórias descrevem uma entrega pela perspectiva de quem usa o resultado. São opcionais e proporcionais: uma tarefa pequena pode ter um cenário curto; uma entrega relevante costuma exigir a jornada completa.

Use [historia-de-uso.md](../templates/historia-de-uso.md). Defina pessoa, objetivo, entrada normal, momentos, critérios e evidências. Para produto sem interface gráfica, adapte os momentos a comandos, dados ou leitura do artefato.

O README é estrutura do template. Histórias e resultados reais pertencem ao projeto e não devem ser copiados para projetos novos.
